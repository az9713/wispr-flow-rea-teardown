How to run flowlite

flowlite runs on Windows with Python 3. It was tested with Python 3.13.5.

  1. Get the code:
    git clone https://github.com/az9713/wispr-flow-rea-teardown
cd wispr-flow-rea-teardown\flowlite
  2. Install the libraries:
    pip install faster-whisper sounddevice keyboard pyperclip numpy
  3. Optional: run the self-test. It transcribes the test file and pastes nothing:
    python flowlite.py --test test.wav
    The correct output is: Let's meet at 6 p.m. on Thursday to review the quarterly report.
  4. Start flowlite. A normal PowerShell window is enough; you do not need administrator.
    python flowlite.py
  5. Wait for Ready. Hold F9 and speak. Ctrl+C to quit. The speech model loads before this line appears. On the first run, the base.en model downloads.
  6. Click into the app where you want the text, such as Notepad, a browser text box or chat.
  7. Hold F9, speak, then release F9.
  8. The text is pasted at the cursor, with one space after it. The console also prints a line like 3.2s audio, 0.85s ASR: '...'.
  9. To stop flowlite, click the console window and press Ctrl+C.

What to expect

  • Model and speed: flowlite uses the base.en model on an NVIDIA GPU with CUDA (float16). If CUDA fails, it prints CUDA failed (...); using CPU and runs on the CPU (int8), which is slower. In the recorded test, 5.1 s of audio took 0.85 s to transcribe on a laptop GPU with 4096 MiB.
  • Language: base.en understands English only.
  • Short presses: a press shorter than 0.25 s is ignored.

Limits

  • F9 also reaches the app. flowlite does not block the key. If an app uses F9 for something, that action also happens.
  • The clipboard is changed for a short time. flowlite copies the text, presses Ctrl+V, waits 0.15 s, then puts the old clipboard text back. If the clipboard held an image or formatted text, that content is lost. A slow app can paste the old clipboard instead of the new text.
  • Administrator windows: flowlite cannot paste into an app that runs as administrator unless the console also runs as administrator.
  • Microphone: flowlite records from the Windows default input device. To use a headset mic, set it as the default in Windows Settings > System > Sound > Input.
  • Not yet tested with a live voice. All passing tests fed a recorded WAV directly into the program. Two tests that played speech from the speakers into the laptop mic both gave empty text (''). If you also get empty text, speak closer to the mic or use a headset mic.
